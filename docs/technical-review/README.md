# Sadari Admin 주요 기능 기술 글

대표 README의 주요 기능 표에서 바로 이동할 수 있도록 관리자 프로젝트에서 다룬 문제와 구현 선택을 기능별로 정리했습니다. 각 글은 현재 저장소의 ServiceImpl, 인증 계층, Mapper와 저장소 구현을 기준으로 처리 순서와 실패 경로를 설명합니다. 사용자 서비스에 적용되는 동작은 관리자 프로젝트의 책임과 구분했으며, 운영 환경에서 확인하지 않은 결과는 설계 또는 남은 검증으로 표시했습니다.

| 기능 | 기술 글 | 핵심 주제 |
| --- | --- | --- |
| 인증과 권한 | [Redis 인증과 메뉴 권한을 API에서 함께 검증](admin-auth-menu-permission.md) | 세션 복원, 역할 부여, HTTP 메서드별 권한, 직접 접근 차단 |
| 메뉴·공통 코드 | [메뉴 계층과 공통 기준 정보를 안전하게 운영](menu-code-management.md) | 3단계 제한, 순환 방지, 하위 메뉴 보호, 코드 중복 검증 |
| 알림 | [알림 템플릿과 아이콘의 저장 책임을 분리](notification-template-icon.md) | 다국어 템플릿, 치환값 허용 목록, PNG 정규화, SVG 외부 참조 차단 |
| 운영 콘텐츠 | [운영 콘텐츠의 작성본과 사용자 노출본을 분리](operational-content-versioning.md) | 버전 생성, 단일 배포본, 행 잠금, HTML 정제 |
